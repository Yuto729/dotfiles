# Ghostty キーバインド設定

## カスタムキーバインド

### 分割操作

| キー | 機能 |
|------|------|
| `Ctrl+Shift+O` | 右に分割 |
| `Ctrl+Shift+E` | 下に分割 |
| `Ctrl+H` | 左の分割へ移動 |
| `Ctrl+J` | 下の分割へ移動 |
| `Ctrl+K` | 上の分割へ移動 |
| `Ctrl+L` | 右の分割へ移動 |
| `Ctrl+Z` | 分割ズーム切替 |
| `Ctrl+Shift+Q` | 分割を閉じる |

## デフォルトキーバインド

### タブ操作

| キー | 機能 |
|------|------|
| `Ctrl+Shift+T` | 新しいタブ |
| `Ctrl+Tab` | 次のタブ |
| `Ctrl+Shift+Tab` | 前のタブ |
| `Ctrl+Shift+W` | タブを閉じる |
| `Alt+1-8` | タブ切り替え |

### コピー/ペースト

| キー | 機能 |
|------|------|
| `Ctrl+Shift+C` | コピー |
| `Ctrl+Shift+V` | ペースト |

### フォント

| キー | 機能 |
|------|------|
| `Ctrl+=` | フォント拡大 |
| `Ctrl+-` | フォント縮小 |
| `Ctrl+0` | フォントサイズリセット |

### その他

| キー | 機能 |
|------|------|
| `Ctrl+Shift+,` | 設定リロード |
| `Ctrl+Shift+I` | インスペクター |
| `Shift+PageUp/Down` | スクロール |

## 注意事項

- `Ctrl+H` はシェルのバックスペースと競合する可能性あり
- `Ctrl+L` はシェルの画面クリアと競合する可能性あり
- `Ctrl+Z` はシェルのサスペンドと競合する可能性あり

問題がある場合は `~/.config/ghostty/config` でキーバインドを変更してください。

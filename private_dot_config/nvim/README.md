# Neovim (LazyVim) キーバインド

`<leader>` はスペースキーです。

## 検索

### ファイル検索

| キー | 機能 |
|------|------|
| `<leader>ff` | ファイル名のあいまい検索 |
| `<leader><leader>` | ファイル名検索（別名） |
| `<leader>fr` | 最近開いたファイル |

### テキスト検索（プロジェクト全体）

| キー | 機能 |
|------|------|
| `<leader>/` | Grep検索（プロジェクト全体） |
| `<leader>sg` | Live Grep（リアルタイム検索） |
| `<leader>sw` | カーソル下の単語を検索 |

### 検索＆置換（grug-far）

| キー | 機能 |
|------|------|
| `<leader>sr` | 検索＆置換パネルを開く |

パネル内の操作（`localleader` は `\`）:

| キー | 機能 |
|------|------|
| `\r` | 全ヒットを一括置換 |
| `<Enter>` | カーソル下の結果へジャンプ |
| `\s` | 結果バッファの手編集を書き戻す（部分置換に便利） |
| `\q` | 結果を quickfix へ送る |
| `\c` | パネルを閉じる |
| `g?` | ヘルプ |

Search欄は正規表現が有効。リテラル検索は Flags欄に `-F`、大小無視は `-i`、隠しファイルは `--hidden`。

### バッファ内検索

| キー | 機能 |
|------|------|
| `<leader>sb` | バッファ内の行を検索 |
| `<leader>sB` | 開いているバッファ内をGrep |

### LSPシンボル検索

| キー | 機能 |
|------|------|
| `<leader>ss` | ドキュメントシンボル（現在のファイル内の関数・クラス等） |
| `<leader>sS` | ワークスペースシンボル（プロジェクト全体の関数・クラス等） |

### その他の検索

| キー | 機能 |
|------|------|
| `<leader>sh` | ヘルプ検索 |
| `<leader>sk` | キーマップ検索 |
| `<leader>st` | TODOコメント検索 |
| `<leader>sT` | TODO/FIX/FIXMEのみ検索 |
| `<leader>sR` | Resume（前回の検索を再開） |

## 移動・ジャンプ（Flash）

| キー | 機能 |
|------|------|
| `s` + 2文字 | 画面内の一致箇所にラベルが出る→ラベルキーで即ジャンプ |
| `S` | Treesitterノード（関数・引数・ブロック等）をラベル選択 |
| `r` | （オペレータ後）リモートFlash：離れた場所を対象に編集 |
| `R` | Treesitter Search（構造単位での検索選択） |

`d`/`y`/`c`/`v` の後に `s` を続けると、ラベル先までを一括で削除/ヤンク/変更/選択できる。
行内の1文字移動は標準の `f`/`F`/`t`/`T` + `;`/`,` を併用。

## Git操作

### Hunk操作（Gitsigns）

| キー | 機能 |
|------|------|
| `]h` / `[h` | 次/前のhunkに移動 |
| `<leader>hr` | hunkをrevert |
| `<leader>hs` | hunkをstage |
| `<leader>hu` | stageを取り消し |
| `<leader>hp` | hunkをプレビュー |

コミット情報（誰がいつ変更したか）は行末に自動表示される（git-blame.nvim）。

### コードレビュー（review.nvim + codediff.nvim）

diff に行コメントを付け、AI に貼る用の Markdown として書き出す。設定は `lua/plugins/review.lua`。

どこからでも使えるキー:

| キー | 機能 |
|------|------|
| `<leader>rr` | 作業ツリーの変更をレビュー（`:Review`） |
| `<leader>rc` | コミットを選んでレビュー |
| `<leader>rb` | ブランチをベースと比較してレビュー |
| `<leader>rn` | 現在行にノートを付ける（ビジュアル選択なら範囲。diff を開かなくても使える） |
| `<leader>re` | カーソル位置のコメントを編集 |
| `<leader>rd` | カーソル位置のコメントを削除 |
| `<leader>rl` | コメント一覧 |
| `<leader>rx` | クリップボードへエクスポート（コメントは残る） |
| `<leader>rX` | 全コメントをアーカイブして消去 |

diff 画面内の操作（readonly モード、既定）:

| キー | 機能 |
|------|------|
| `i` | コメント追加（種類をメニューで選択。ビジュアル選択なら範囲コメント） |
| `F` | ファイル全体へのコメント |
| `e` / `d` | カーソル位置のコメントを編集 / 削除 |
| `c` | 全コメント一覧（選ぶとそのコメントへ飛ぶ。別ファイルでも可） |
| `]n` / `[n` | 次/前のコメントへ |
| `<Tab>` / `<S-Tab>` | 次/前のファイル |
| `]c` / `[c` | 次/前の変更箇所（hunk） |
| `f` | ファイルパネルの表示切替 |
| `<leader>e` | ファイルパネルにフォーカス |
| `t` | 左右並び ⇔ inline（unified）切替 |
| `C` | エクスポートしてプレビュー（コメントは残る） |
| `q` | 閉じるだけ（コメントは残り、エクスポートもしない） |
| `R` | readonly ⇔ edit モード切替 |
| `<leader>hs` / `<leader>hu` / `<leader>hr` | hunk を stage / unstage / 破棄 |
| `<leader>hS` | 現在のファイルを stage / unstage |
| `?` / `g?` | review.nvim / codediff.nvim のヘルプ |

コメント入力ポップアップ:

| キー | 機能 |
|------|------|
| `<C-s>` | 確定 |
| `<Tab>` | 種類を切替（Note / Suggestion / Issue / Praise） |
| `<Enter>` | 改行 |
| `<Esc>` → `q` | キャンセル |

edit モード（`R` で切替）では単キーの代わりに `\cc`（種類選択）、`\cn` / `\cs` / `\ci` / `\cp`（種類指定）、`\cf`（ファイル）、`\ce`（編集）、`\cd`（削除）を使う。

既定から変えた点:

- `S`（sidekick.nvim へ送信）は無効。sidekick 未導入で、Flash Treesitter の `S` を潰さないため
- `<C-r>`（全コメント消去）は無効。redo と被るため `<leader>rX` に移した
- `q`（エクスポートして全消去して閉じる）は無効。誤爆防止のため、`q` は閉じるだけにした。ラウンドを締めるときは `C` か `<leader>rx` でエクスポートしてから `<leader>rX`（または `:Review close` で一括）
- codediff の `<leader>b`（パネル開閉）は無効。バッファ操作のプレフィックスと被るため `f` を使う
- codediff の `-`（ファイルを stage）は `<leader>hS` に移した。Oil の `-` と被り誤って stage するのを避けるため
- コメント一覧（`c` / `<leader>rl`）を自前の関数に差し替えた。本家 v1.10.1 は別ファイルのコメントへ飛べないため。diff を開いていないときは、そのファイルを開いて飛ぶ

使い方メモ:

- resolve（解決済みにする）機能は無い。片付いたコメントは `d`（diff 外では `<leader>rd`）で削除する。個別に削除したものはアーカイブに残らない
- 削除された行（旧側）にコメントするには、左右並び表示で `<C-w>h` で左ペインに移ってから `i`
- diff 画面内では `f` / `F` / `t` の行内移動は使えない（`s` の Flash は使える）
- コメントは作業ツリーのパス単位で `~/.local/share/nvim/review/` に保存される。git worktree ごとに別々で共有されず、対象は Neovim の作業ディレクトリのリポジトリ
- `<leader>rX` や `:Review close` で消したコメントは `archive/` に30日残る

バージョンは review.nvim `v1.10.1`、codediff.nvim `v4.0.6` に tag で固定している（`:Lazy update` でも上がらない）。一覧の差し替えが codediff.nvim の内部APIに依存しているため。上げるときは `lua/plugins/review.lua` の `tag` を書き換え、`c` で別ファイルへ飛べるかを確認する。本家の修正は [PR #54](https://github.com/georgeguimaraes/review.nvim/pull/54) で出ている（2026-10-13 時点で未マージ）。これが入ったリリースに上げれば、差し替え（`list_comments` と `config`）は削除できる。

## 一覧・診断（Trouble）

診断・参照・シンボルなどをプレビュー付きの一覧窓で辿る。同じキーで開閉トグル。

| キー | 機能 |
|------|------|
| `<leader>xx` | 診断一覧（プロジェクト全体） |
| `<leader>xX` | 診断一覧（現在ファイルのみ） |
| `<leader>cs` | シンボル一覧（アウトライン） |
| `<leader>cS` | LSP参照/定義など |
| `<leader>xL` | location list |
| `<leader>xQ` | quickfix list |
| `<leader>xt` | TODO一覧 |
| `]q` / `[q` | 次/前の項目（窓を開かず巡回） |

窓の中の操作:

| キー | 機能 |
|------|------|
| `<Enter>` | その場所へジャンプ |
| `o` | ジャンプして窓を閉じる |
| `<C-s>` / `<C-v>` | 水平/垂直分割で開く |
| `}` / `{` | 次/前の項目 |
| `p` | プレビュー |
| `q` | 閉じる |
| `r` | 再取得（リフレッシュ） |

# Neovim (LazyVim) キーバインド

`<leader>` はスペースキーです。

## 検索

### ファイル検索

| キー | 機能 |
|------|------|
| `<leader>ff` | ファイル名のあいまい検索 |
| `<leader><leader>` | ファイル名検索（別名） |
| `<leader>fr` | 最近開いたファイル |

### テキスト検索（プロジェクト全体）

| キー | 機能 |
|------|------|
| `<leader>/` | Grep検索（プロジェクト全体） |
| `<leader>sg` | Live Grep（リアルタイム検索） |
| `<leader>sw` | カーソル下の単語を検索 |

### 検索＆置換（grug-far）

| キー | 機能 |
|------|------|
| `<leader>sr` | 検索＆置換パネルを開く |

パネル内の操作（`localleader` は `\`）:

| キー | 機能 |
|------|------|
| `\r` | 全ヒットを一括置換 |
| `<Enter>` | カーソル下の結果へジャンプ |
| `\s` | 結果バッファの手編集を書き戻す（部分置換に便利） |
| `\q` | 結果を quickfix へ送る |
| `\c` | パネルを閉じる |
| `g?` | ヘルプ |

Search欄は正規表現が有効。リテラル検索は Flags欄に `-F`、大小無視は `-i`、隠しファイルは `--hidden`。

### バッファ内検索

| キー | 機能 |
|------|------|
| `<leader>sb` | バッファ内の行を検索 |
| `<leader>sB` | 開いているバッファ内をGrep |

### LSPシンボル検索

| キー | 機能 |
|------|------|
| `<leader>ss` | ドキュメントシンボル（現在のファイル内の関数・クラス等） |
| `<leader>sS` | ワークスペースシンボル（プロジェクト全体の関数・クラス等） |

### その他の検索

| キー | 機能 |
|------|------|
| `<leader>sh` | ヘルプ検索 |
| `<leader>sk` | キーマップ検索 |
| `<leader>st` | TODOコメント検索 |
| `<leader>sT` | TODO/FIX/FIXMEのみ検索 |
| `<leader>sR` | Resume（前回の検索を再開） |

## ファイルエクスプローラー

| キー | 機能 |
|------|------|
| `-` | Oil.nvimを開く（親ディレクトリ） |

### Oil.nvim内の操作

| キー | 機能 |
|------|------|
| `Enter` | ファイルを開く / ディレクトリに入る |
| `-` | 親ディレクトリへ |
| `q` | 閉じる |

## 移動・ジャンプ（Flash）

| キー | 機能 |
|------|------|
| `s` + 2文字 | 画面内の一致箇所にラベルが出る→ラベルキーで即ジャンプ |
| `S` | Treesitterノード（関数・引数・ブロック等）をラベル選択 |
| `r` | （オペレータ後）リモートFlash：離れた場所を対象に編集 |
| `R` | Treesitter Search（構造単位での検索選択） |

`d`/`y`/`c`/`v` の後に `s` を続けると、ラベル先までを一括で削除/ヤンク/変更/選択できる。
行内の1文字移動は標準の `f`/`F`/`t`/`T` + `;`/`,` を併用。

## バッファ操作

| キー | 機能 |
|------|------|
| `<leader>,` | バッファ一覧 |
| `<leader>bb` | 前のバッファに切り替え |
| `<leader>bd` | バッファを閉じる |
| `<leader>bo` | 他のバッファをすべて閉じる |
| `<leader>bD` | バッファとウィンドウを閉じる |
| `H` | 前のバッファへ |
| `L` | 次のバッファへ |

## ターミナル / スクラッチ

| キー | 機能 |
|------|------|
| `Ctrl+/` | フローティングターミナル |
| `<leader>ft` | ターミナル（プロジェクトルート） |
| `<leader>fT` | ターミナル（カレントディレクトリ） |
| `<leader>.` | スクラッチバッファをトグル（snacks） |

## Git操作

### Hunk操作（Gitsigns）

| キー | 機能 |
|------|------|
| `]h` / `[h` | 次/前のhunkに移動 |
| `<leader>hr` | hunkをrevert |
| `<leader>hs` | hunkをstage |
| `<leader>hu` | stageを取り消し |
| `<leader>hp` | hunkをプレビュー |

コミット情報（誰がいつ変更したか）は行末に自動表示される（git-blame.nvim）。

## LSP（定義ジャンプなど）

| キー | 機能 |
|------|------|
| `gd` | 定義へジャンプ |
| `gr` | 参照一覧 |
| `gI` | 実装へジャンプ |
| `gy` | 型定義へジャンプ |
| `K` | ホバードキュメント |
| `Ctrl+o` | 前の位置に戻る |
| `Ctrl+i` | 次の位置に進む |

### コードアクション・編集

| キー | 機能 |
|------|------|
| `<leader>ca` | コードアクション（クイックフィックス等） |
| `<leader>cr` | リネーム |
| `<leader>cA` | ソースアクション |
| `<leader>cf` | フォーマット（手動。保存時自動整形はオフ） |
| `<leader>cR` | ファイル名を変更（参照も更新） |
| `<leader>cc` | Codelens実行 |

### Peek（フローティングプレビュー）

| キー | 機能 |
|------|------|
| `gpd` | 定義をフローティングでプレビュー |
| `gpt` | 型定義をプレビュー |
| `gpi` | 実装をプレビュー |
| `gpr` | 参照をプレビュー |
| `gP` | プレビューウィンドウをすべて閉じる |

### 診断（エラー/警告）ジャンプ

| キー | 機能 |
|------|------|
| `]d` | 次の診断（エラー/警告）へ |
| `[d` | 前の診断へ |
| `]e` | 次のエラーへ |
| `[e` | 前のエラーへ |
| `]w` | 次の警告へ |
| `[w` | 前の警告へ |
| `<leader>cd` | 行の診断を表示 |
| `<leader>yc` | 診断メッセージをクリップボードにコピー |

## 一覧・診断（Trouble）

診断・参照・シンボルなどをプレビュー付きの一覧窓で辿る。同じキーで開閉トグル。

| キー | 機能 |
|------|------|
| `<leader>xx` | 診断一覧（プロジェクト全体） |
| `<leader>xX` | 診断一覧（現在ファイルのみ） |
| `<leader>cs` | シンボル一覧（アウトライン） |
| `<leader>cS` | LSP参照/定義など |
| `<leader>xL` | location list |
| `<leader>xQ` | quickfix list |
| `<leader>xt` | TODO一覧 |
| `]q` / `[q` | 次/前の項目（窓を開かず巡回） |

窓の中の操作:

| キー | 機能 |
|------|------|
| `<Enter>` | その場所へジャンプ |
| `o` | ジャンプして窓を閉じる |
| `<C-s>` / `<C-v>` | 水平/垂直分割で開く |
| `}` / `{` | 次/前の項目 |
| `p` | プレビュー |
| `q` | 閉じる |
| `r` | 再取得（リフレッシュ） |

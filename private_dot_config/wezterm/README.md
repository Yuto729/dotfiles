# WezTerm キーバインド設定

## カスタムキーバインド

### 分割操作

| キー | 機能 |
|------|------|
| `Ctrl+Shift+\|` | 水平分割（左右） |
| `Ctrl+Shift+_` | 垂直分割（上下） |
| `Ctrl+H` | 左のペインへ移動 |
| `Ctrl+J` | 下のペインへ移動 |
| `Ctrl+K` | 上のペインへ移動 |
| `Ctrl+L` | 右のペインへ移動 |
| `Ctrl+Z` | ペインズーム切替（現在のペインを最大化/他を隠す） |
| `Ctrl+Shift+Q` | ペインを閉じる |
| `Ctrl+Alt+H` | ペインを左に広げる |
| `Ctrl+Alt+J` | ペインを下に広げる |
| `Ctrl+Alt+K` | ペインを上に広げる |
| `Ctrl+Alt+L` | ペインを右に広げる |

### タブ操作

| キー | 機能 |
|------|------|
| `Ctrl+Shift+H` | 前のタブ |
| `Ctrl+Shift+L` | 次のタブ |

### 透過操作

| キー | 機能 |
|------|------|
| `Ctrl+Shift+B` | 透明/不透明をトグル |
| `Ctrl+Shift+↑` | 透明度を上げる（不透明に） |
| `Ctrl+Shift+↓` | 透明度を下げる（透明に） |

## デフォルトキーバインド

### タブ操作

| キー | 機能 |
|------|------|
| `Ctrl+Shift+T` | 新しいタブ |
| `Ctrl+Tab` | 次のタブ |
| `Ctrl+Shift+Tab` | 前のタブ |
| `Ctrl+Shift+W` | タブを閉じる |

### コピー/ペースト

| キー | 機能 |
|------|------|
| `Ctrl+Shift+C` | コピー |
| `Ctrl+Shift+V` | ペースト |

### フォント

| キー | 機能 |
|------|------|
| `Ctrl+=` | フォント拡大 |
| `Ctrl+-` | フォント縮小 |
| `Ctrl+0` | フォントサイズリセット |

### その他

| キー | 機能 |
|------|------|
| `Ctrl+Shift+R` | 設定リロード |
| `Ctrl+Shift+P` | コマンドパレット |
| `Shift+PageUp/Down` | スクロール |

## 注意事項

- `Ctrl+H` はシェルのバックスペースと競合する可能性あり
- `Ctrl+L` はシェルの画面クリアと競合する可能性あり
- `Ctrl+Z` はシェルのサスペンドと競合する可能性あり

問題がある場合は `~/.config/wezterm/wezterm.lua` でキーバインドを変更してください。

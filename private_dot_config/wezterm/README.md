# WezTerm キーバインド設定

`Leader` = `Ctrl+q`（1秒以内に次のキーを押す）

## カスタムキーバインド

### ペイン操作

| キー | 機能 |
|------|------|
| `Ctrl+H/J/K/L` | ペイン間移動 |
| `Leader+v` | 縦分割 |
| `Leader+h` | 横分割 |
| `Leader+x` | ペインを閉じる |
| `Leader+z` | ペインズーム（最大化/他を隠す） |
| `Leader+s` | リサイズモードに入る |

### リサイズモード (Leader+s)

| キー | 機能 |
|------|------|
| `h/j/k/l` | ペインサイズを調整 |
| `Enter` / `Escape` | モード終了 |

### タブ操作

| キー | 機能 |
|------|------|
| `Ctrl+Shift+H` | 前のタブ |
| `Ctrl+Shift+L` | 次のタブ |
| `Leader+t` | タブ移動モードに入る |

### タブ移動モード (Leader+t)

| キー | 機能 |
|------|------|
| `h` | タブを左へ移動 |
| `l` | タブを右へ移動 |
| `Enter` / `Escape` | モード終了 |

### Workspace

| キー | 機能 |
|------|------|
| `Leader+w` | ワークスペース一覧 |
| `Leader+$` | ワークスペース名変更 |
| `Leader+W` | 新しいワークスペース作成 |

### コピーモード (Leader+[)

| キー | 機能 |
|------|------|
| `h/j/k/l` | カーソル移動 |
| `w/b/e` | 単語移動 |
| `0/^/$` | 行頭・行末移動 |
| `g/G` | 先頭・末尾へ |
| `Ctrl+u/d` | 半ページスクロール |
| `Ctrl+b/f` | ページスクロール |
| `v` | 選択モード |
| `V` | 行選択モード |
| `Ctrl+v` | 矩形選択モード |
| `y` | コピー |
| `Enter` | コピーして終了 |
| `Escape` / `q` | モード終了 |

### 透過操作

| キー | 機能 |
|------|------|
| `Ctrl+Shift+↑` | 透明度を上げる（不透明に） |
| `Ctrl+Shift+↓` | 透明度を下げる（透明に） |

### コピー/ペースト

| キー | 機能 |
|------|------|
| `Ctrl+Shift+C` | コピー |
| `Ctrl+Shift+V` | ペースト |

## デフォルトキーバインド

### タブ操作

| キー | 機能 |
|------|------|
| `Ctrl+Shift+T` | 新しいタブ |
| `Ctrl+Tab` | 次のタブ |
| `Ctrl+Shift+Tab` | 前のタブ |
| `Ctrl+Shift+W` | タブを閉じる |

### フォント

| キー | 機能 |
|------|------|
| `Ctrl+=` | フォント拡大 |
| `Ctrl+-` | フォント縮小 |
| `Ctrl+0` | フォントサイズリセット |

### その他

| キー | 機能 |
|------|------|
| `Ctrl+Shift+R` | 設定リロード |
| `Ctrl+Shift+P` | コマンドパレット |
| `Shift+PageUp/Down` | スクロール |

## 注意事項

- `Ctrl+H` はシェルのバックスペースと競合する可能性あり
- `Ctrl+L` はシェルの画面クリアと競合する可能性あり

問題がある場合は `~/.config/wezterm/wezterm.lua` でキーバインドを変更してください。
